## Documentation scope

This documentation describes the current plugin functionality neutrally and without version-specific change wording.

Covered areas:

- Reolink UID/Wi-Fi cameras without Reolink Hub
- Reolink PoE/IP cameras
- RTSP/ONVIF proxy
- MQTT and UDP
- Loxone Config export
- Snapshot and status endpoints
- Setup guard and systemd service
- MQTT Gateway reload with process cleanup
